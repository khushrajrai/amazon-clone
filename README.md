# **Amazon UI Clone – E-Commerce Landing Page**

A fully responsive front-end clone of Amazon’s homepage, built to practice real-world e-commerce layout design, component structuring, and UI/UX consistency.

---

## 🚀 **Features**

* Fully responsive design (mobile, tablet, and desktop)
* Amazon-style navigation bar with search box & menus
* Product category cards and multi-row product grids
* Clean footer section replicating Amazon’s layout
* Pixel-accurate UI built using pure HTML & CSS (no frameworks)

---

## 🛠️ **Tech Stack**

* **HTML5**
* **CSS3** (Flexbox, Grid)

---

## 📁 **Project Structure**

```
amazon-ui-clone/
│── index.html
│── style.css
```
---

## 🔧 **How to Run**

1. Clone this repository

   ```bash
   git clone https://github.com/your-username/amazon-ui-clone.git
   ```
2. Open `index.html` in any browser
   (No installation needed)

---

## 📌 **Purpose**

This project was created to strengthen front-end development skills and practice building real-world e-commerce UI components without using libraries or frameworks.
